# Meesho Clone – Modern UI/UX Design Guide ## 1. Design Style (Modern Look & Feel) - **Target:** Clean + minimal, Instagram + Meesho hybrid, Mobile-first, Fast navigation. - **Principles:** Soft colors, 12px–20px rounded corners, Shadow-based cards, Bottom navigation, Bold CTA buttons. ## 2. Color Palette - **Primary:** #FF3F6C (Pink/Meesho vibe) - **Secondary:** #6C63FF (Modern purple) - **Background:** #F8F9FB - **Text Dark:** #1A1A1A - **Text Light:** #7A7A7A - **Success:** #22C55E - **Error:** #EF4444 ## 3. Typography - **Heading:** Poppins / Inter (H1: 22–24px, H2: 18px) - **Body:** Regular clean font (14–16px, Small: 12px) ## 4. User App UI (Customer + Reseller) - **Home:** Search bar, Banner carousel, Horizontal categories, 2-column product grid with "Resell & Earn" badges. - **Product Detail:** Image slider, Price + margin option, Description, Reviews, Sticky "Add to Cart", "Buy Now", and highlighted "Resell" buttons. - **Resell Screen:** Margin input, Auto profit calculation, Share to WhatsApp. - **Cart/Checkout:** Simple list, Address selector, COD-first payment. - **Profile:** Orders, Wallet, Earnings, Settings. ## 5. Supplier App UI - **Dashboard:** Total Orders, Revenue, Pending Orders cards. - **Add Product:** Large image upload, Name, Price, Stock, Description with clean input fields. ## 6. Navigation (Bottom Nav) - **User:** Home, Search, Orders, Earnings, Profile. - **Supplier:** Dashboard, Products, Orders, Profile.
